## 2. The entries

Each entry's ledger `notes` say where the code went and every difference from upstream; this section is the short
form.

### 51. Recommendations: the tab keeps its rows; Back on mobile

A Home tab that is only hidden keeps its rows; an open category page holds one history entry, so Back (the button,
the browser's, Android's) closes it; the Android app's `NavigationHelper.goBack` is wrapped so Back closes a More Info
modal or a category page, or returns from a JE tab to Home; a `jeTab` without `tab=N` is not followed; the rows' edge
masks apply only to devices that hover. In `client/src/features/seerr/recommendations` and
`client/src/features/chrome/native-tabs.ts`. The wrapper waits for `NavigationHelper` with a capped `setTimeout`
retry (performance guard R5 forbids a DOM-polling interval). **Found in upstream while porting:** the first pop after
a reload with a category open is taken for a navigation and closes the category under a More Info modal; the port
checks whether the pop landed on the category's own entry (found bug
`NEW-20261116-071714-upstream-c165a07b-closing-more-info-over-a-recom`, with a lab script that shows it on upstream's
build).

### 52. Media Tags: hide individual tags

`PluginConfiguration.TagHiddenValues`, the resolver, the settings digest and the page field on the server at the
moved paths; the rules live in `Shared/MediaTags/PosterTags/TagHiddenRules.cs` so the contracts generator can
compile the configuration model alone. The typed bootstrap gains `TagHiddenValues` and `TagHiddenAgeRatings`. Client
in `client/src/features/media-tags` (`pipeline/tag-hidden.ts`, `layout/present.ts`, the admin editor's Hide switch
and hidden rows). The editor's tables moved to `admin/tag-styles-parts.ts`, which lowers `tag-styles-editor.ts`'s
size baseline from 1119 to 1106 lines.

### 53 and 54. Media Tags: tag text

`TagTextOverrides` end to end, the tab renamed "Colours and text". 54 is upstream regenerating its inventory and
flag groups for 53 and goes `with` it; here the same files are regenerated by `je12 regen` and
`scripts/generate_config_flag_groups.py`.

### 55. Media Tags: incomplete custom rules survive an auto-save

The rewrite's own guard compared the stored rules as text and never matched, because the server leaves out a rule's
empty `Icon`. Upstream's comparison of collected rules replaces it (`custom-rules-editor.ts` `matches(config)`).
Upstream has no test; this tree gains a page test whose server stand-in drops the empty member as the real one does.

### 56. Seerr: remove watched requests, and a Remove request button

`AutoRequestRemovalTask` and `RequestRemovalPlanner` in `Features/Seerr`, the route `DELETE arr/requests/{requestId}`
and the rows' `canRemove` in `Features/Downloads/JeDownloadsController.Requests.cs`, the admin section, and the
Requests page's button in `client/src/features/downloads`. The button follows this tree's rules for a request action
(only a request the loaded list says may be removed, checked again after the confirmation, one DELETE per request).
This port adds a route, an action and a registration: section 5.

### 57. Player: subtitle sync

Upstream's 1,642-line `subtitle-sync.js` is five TypeScript modules and a stylesheet in
`client/src/features/player/subtitle-sync` (`lines.ts`, `watch.ts`, `track.ts`, `view.ts`, `dialog.ts`), bundled into
`enhanced/player/auto-skip.js` because `component-scripts.json` is pinned. The setting `SubtitleSyncButtonEnabled`
goes through the configuration, the typed bootstrap, the settings panel and the admin page with their records
(`tests/fixtures/admin-config-baseline.json`, the What's New index, `per-user-props.ts`, the flag groups).
`pausescreen.ts` leaves keys and focus to the dialog; its credentials parse moved to `pause-view.ts` to keep the file
under its line cap. Differences: a toast renders markup here, so the dialog's toasts go through `JE.t` with the
offset escaped (the first version escaped the whole string and showed the icon's markup as text; the lab run caught
it); the accent colour reaches the stylesheet only when it is a plain CSS colour.

### 59. Player shortcuts without a `<video>` (Jellyfin Desktop's mpv)

Upstream's new `osd-playback.js` is `client/src/features/shared/osd-playback.ts`, bundled into `playback.js` (which
publishes it as `JE.internals.osdPlayback`, as upstream) and into `bookmarks.js` (which imports it, since a feature
may not read another's internals slot). Its additions to `playback.js` are `player/osd-seek-history.ts`,
`player/osd-settings-menu.ts`, the OSD branch of `segment-controls.ts` and the no-`<video>` branches of the existing
modules; `chrome/events.ts` no longer needs a `<video>` for player shortcuts. Bookmarks read the player through
`bookmarks/player-surface.ts`, which shrinks `bookmarks.ts` from 849 to 842 lines (baseline lowered). Differences: the
seek listeners live only while the OSD is watched, and the kept state is dropped on a navigation or an account
change; jellyfin-web's aspect ratio name is escaped in its toast. **Found in upstream:** deleting the last bookmark
leaves its marker on the timeline (found bug `NEW-20261116-092505-upstream-3f8e4724-deleting-the-last-player-bookm`);
this tree never had it.
