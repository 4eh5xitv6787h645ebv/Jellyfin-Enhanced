## 2. The entry

### 94. A lighter Home screen: lazy feature bundles and cheaper tags (#1088)

What upstream changed. The commit squashes 48 commits. Its headline: the 195 component modules no longer run as one
script on every page. `js/component-groups.json` puts them in groups; a page loads `core` and the groups its route,
the configuration and the user's settings need, in one request (`bundle.js?g=core,tags,…`), and more groups when a
route, a Home tab, a video or a call needs them. `Services/ClientScriptBundle.cs` serves any set of groups as one script
with its source map, the bootstrap answer carries the group list (`ComponentGroups`), and `plugin.js` resolves, loads
and runs the groups, with stage 6 taken from a table so that a group loaded later runs its own initializers. Around it
come about 40 independent performance changes to the poster tags and a few other modules, listed in section 3.

**Why it is deferred.** Two things the headline needs are frozen here, and an unattended sync may change neither:

1. **Two existing contract lines.** Upstream adds `[FromQuery] string? g = null` to `GetScriptBundle` and
   `GetScriptBundleMap`. With only those two signatures applied to `JePlatformController.Assets.cs`,
   `RouteAuthSnapshotTests.RouteVerbAuthAndBindingMatchTheSnapshot` fails with
   ([`p94-contract-tests.txt`](upstream-sync-evidence/p94-contract-tests.txt)):
   ```
   -   {"verb":"GET","route":"JellyfinEnhanced/bundle.js",…,"action":"GetScriptBundle","apiBehavior":true,"parameters":[]},
   -   {"verb":"GET","route":"JellyfinEnhanced/bundle.js.map",…,"action":"GetScriptBundleMap","apiBehavior":true,"parameters":[]},
   +   {"verb":"GET","route":"JellyfinEnhanced/bundle.js",…,"action":"GetScriptBundle","apiBehavior":true,"parameters":["g:Query"]},
   +   {"verb":"GET","route":"JellyfinEnhanced/bundle.js.map",…,"action":"GetScriptBundleMap","apiBehavior":true,"parameters":["g:Query"]},
   ```
   These are changed lines, not additions. The probe was reverted; it is not on the branch.
2. **The pinned module list.** Gate FE G requires `js/component-scripts.json` and the key set of every
   `client/entries/*.json` to equal `restructure-base` (`scripts/restructure-gates.sh`, step "component-scripts.json and
   client/entries output keys vs restructure-base"). Upstream adds `tags/status-tag-backdrop.js` (the painted status-tag
   backdrop, 1,716 lines, fetched as its own group `tag-status-backdrop` when the first status tag is drawn) as a module
   of its own. Also, `component-groups.json` is written over upstream's module list, and this tree's list is not
   upstream's: it folds several of upstream's modules into others (for example the discovery modules, the OSD playback
   and subtitle-sync modules, `tags/maintainerr-item-menu.js` and `extras/leavingsoon-page.js`), so the split has to
   be redone for this tree, not copied.

**Why the rest is not ported on its own.** About 40 of the 48 commits need neither the contract change nor a new
module, but several of them assume the loader: the status tags ask `JE.loader.ensure` for the painter, the loader sets
the `window.JE` alias that the Bookmarks view used to set, the player functions are optional until the player group has
loaded, the item tag editor fetches the `settings` group, and the bundle budgets and loader tests measure groups. Which
parts stand alone is a judgement about this tree's architecture that the maintainer should make, so the commit is left
whole. Section 3 lists the parts and where each would go here, so that a later run can start from it.

**What it needs.** A maintainer's decision, recorded in the entry's `needs`, on how lazy loading takes shape here:

- accept the two changed `bundle.js` and `bundle.js.map` lines and an addition to `component-scripts.json` and
  `client/entries` for the painter, and a later run ports the whole commit, with those lines in its last commit for
  review; or
- name another shape: an added route for group bundles (additions only, which an unattended run may land), or group
  bundles built as outputs of their own; or
- split the entry: port now the parts that need neither (section 3, "stands alone") and keep the loader and the painter
  deferred.
