## 2. The entries

### 37. perf(tags): stop every tag-cache delta re-sending a rebuild's entries (#1053)

Upstream's PR has two commits.

- **The first is already here** as `680e243c` (`perf(media-tags): a tag-cache cursor covers the stamps its entries
  carry`, on the main line since 2026-11-12): the build publish and the disk load set the delta cursor to the later
  of the clock and the newest entry stamp, and every in-place pass (awards, custom tags, Leaving soon, logos,
  scenes, source ratings, the update queue) advances it through `TouchLastModified`, which also counts the newest
  entry stamp. Upstream's hunks to `Services/TagCache*.cs` are this tree's to
  `Features/MediaTags/Services/TagCache/TagCache*.cs`, and its two tests for that half are already in
  `tests/backend/Features/MediaTags/PosterTags/`.
- **The second is ported** (`9b8a1aa3`): `NextStamp` also clears the delta cursor. A pass that set the cursor to the
  clock, followed in the same millisecond by another pass's first stamp, gave that entry a stamp equal to the
  cursor; deltas return entries strictly after the cursor, so a browser holding it never received the entry. The
  same happened after a restart while the clock was behind the saved cursor. The code line is upstream's.

Differences from upstream: `NextStamp`'s doc comment is reworded to keep `TagCacheService.cs` at 4,084 lines (its
allow-list entry only shrinks); `TouchLastModified` keeps this tree's shorter comment, which leaves out upstream's
note that its callers hold `_rebuildLock` (true here too). No cached-output version moves: what an entry holds and
how tags resolve do not change, only which stamp a new entry gets.

Proof: upstream's `AStampIsAlwaysLaterThanTheCursorAPassPublished`, unchanged in `CustomTagRulesTests`, fails on the
branch start (`stamp after cursor 1794544018824`, the first iteration) and passes after, three times alone; the 95
tests of `CustomTagRulesTests` and `PerfRound2TagCacheResponseTests` pass. No lab comparison: the fault needs two
passes in one millisecond (or a clock behind the saved cursor), which no lab command reproduces on demand. The
recorded smoke below ran on a build with this change (tagged posters, the Media Tags hub and the delta reads all
`ok`).
