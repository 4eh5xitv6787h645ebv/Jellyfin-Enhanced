0-5 and leaves out the % symbol; a raw fallback value keeps its own scale. The admin page has upstream's Rating Scale
select under Show % Symbol, in the MDBList card and in its Services-tab copy (the engine's mirror), with its What's New
index line, load (an unknown stored value shows 0-100), save and its place under Enable MDBList Ratings. Upstream's
test file applies unchanged at its own path; a new admin test covers load and save; the admin fixture lists the new id.

in a Boolean row.

3.5); the public configuration, the client and the admin page are the build's own. Upstream's build and this branch
read the same in all three cases: scale 10 with % on draws `RT Critic 8.5, IMDb 6.4, Roger Ebert 3.5`; scale 5 draws

score)`, `0-10`, `0-5` and shows the stored value (and its Services-tab copy shows the same value). On the main line
