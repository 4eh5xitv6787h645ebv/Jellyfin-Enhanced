was shown, so with Media Tags the tab kept in the session a link to a Media Tags section opened the session's section;
and its `setHash` wrote the page name with `+` (URLSearchParams) where Jellyfin's links write `%20`.

- **Already here:** upstream's own case. The b0a8a963 port follows the address the page opened at, so that link already
  opened its section (lab row F below: Layout on upstream's parent `6b8c9218`, Colours on this tree before and after).

  here: pressing the Media Tags tab's own button again, or ending a settings search (which shows the saved tab again),
  took the section out of the address while the tab still showed it, so a reload in a new session or a copied link
  opened Overview (rows C, D, E). The `+` was cosmetic on Jellyfin 12.4: the dashboard menu stays marked and a reload
  works with either (rows A, B, every build).

  ported b0a8a963) and its edit of the in-place link test (this tree restated that test in the same port; it passes
