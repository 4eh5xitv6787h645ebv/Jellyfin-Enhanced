Hidden Content
visibility
Hidden Content lets users hide individual items from Home and Library views and browse them from a dedicated Hidden Content page. Per-user state with a server-wide enable/disable kill switch.
Enable or disable the Hidden Content feature server-wide. When disabled, hide buttons, filtering, sidebar navigation, and settings panel options are all removed. User data is preserved and restored when re-enabled.
Adds Hidden Content as its own tab on the Home page, no external plugin needed.
Recommended on Jellyfin 12's experimental layout (the default).
Replaces the default Hidden Content page with a Plugin Pages implementation.
Note: Jellyfin must be restarted after enabling this option for the first time for changes to take effect. check_circlePlugin Pages detected

Embed Hidden Content in Custom Tabs: check_circleCustom Tabs detected

Display the Hidden Content page in a Custom Tabs tab instead of the sidebar link.

You need the Custom Tabs plugin.

  1. Install the Custom Tabs plugin and all its prerequisites.
  2. Navigate to Dashboard > Plugins > Custom Tabs and add a new tab.
  3. Add "Display Text" according to your preference (e.g., "Hidden Content").
  4. Copy the code below and paste it into the 'HTML Content' field.
<div class="jellyfinenhanced hidden-content"></div>

More Settings
tune
Defaults for new users and the Overwrite everyone's personal settings button in Overview > Quick Actions. Existing users keep their current settings unless you click that button.
When on, Hidden Content starts active for new users, so they can hide things straight away and the filtering takes effect immediately. When off, users have to turn it on themselves first.
When on, the Hide button shows up across the apps so users can hide things they don't want to see. When off, no Hide button appears anywhere, but users can still bring back items they've already hidden from the Hidden Content page.
When on, clicking Hide asks "are you sure?" first. Turn off for one-click hiding. Items can always be brought back from the Hidden Content page.
Adds a Hide button to Seerr search and discover results, so users can hide a movie or show even before it's been added to their library.
Adds a Hide button to the row of action buttons on movie, show, and episode detail pages.
Adds a small eye icon to every poster on the home and library pages, so users can hide an item without opening it first. Off by default because some people find the icon on every poster busy.
Adds a Hide button to actor cards. Hiding an actor hides every movie or show they appear in until you bring them back.
When on, hidden items don't appear when users browse a library (Movies, Shows, etc.) or in the suggestion rows on a details page. Turn off if users still want to see hidden items while browsing.
When on, hidden items don't appear in search results. Off by default because most people still want to be able to search for something they hid in order to bring it back.
When on, hidden items don't appear in the Continue Watching row on the home page. Required for the "Remove from Continue Watching" button to actually do anything.
When on, hidden series don't appear in the Next Up row on the home page. Recommended on so a show users have hidden doesn't keep being suggested as the next thing to watch.
When on, hidden series don't appear on the Upcoming Episodes page.
When on, hidden items don't appear in the "Because you watched..." and "Suggested for you" rows on the home and details pages.
When on, hidden items don't appear on the Discovery page (genre, similar, and recommended sections).
When on, hidden series don't show up on the Calendar page's list of upcoming episodes.
When on, hidden items don't appear on the Requests page (the combined view of Sonarr, Radarr, and Seerr requests).
Warning: Extremely not recommended for average users. Will break things. Only turn this on if you 100% know what you want to use it for. Lets users hide whole collections, libraries, or playlists in addition to individual movies and shows.
Admin Controls
Adds a "user filter" dropdown on the Hidden Content page so an admin can see what any user has hidden, with an Edit toggle to unhide items or add new ones from the library or Seerr on that user's behalf. Turn this off if you don't want to edit/manage other users' hidden content.
