User Reviews
info Completely independent of Elsewhere being enabled and TMDB Reviews being enabled
Allows users to write reviews and rate items in the library.
When enabled, reviews written by Jellyfin users marked as "Hide this user from login screens" are hidden from non-admin viewers. Admins always see all reviews.
When enabled, reviews written by Jellyfin users marked as "Disable this user" are hidden from non-admin viewers. Admins always see all reviews.
