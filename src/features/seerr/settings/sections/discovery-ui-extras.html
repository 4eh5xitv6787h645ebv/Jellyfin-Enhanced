Discovery & UI Extras
When enabled, clicking a Seerr result title or poster opens an in-app More Info modal.
When disabled, clicking will open the item in Seerr.
For a Seerr result that's already available in your library, clicking the poster goes straight to the Jellyfin item, just like the title link already does. If "Open results in More Info modal" above is enabled, the modal can no longer be opened by clicking the poster of an available item.
When enabled, a small report icon will be added to item action icons allowing users to report playback/content issues to Seerr.
When enabled, the report issue button turns orange and shows a count badge if the item has open issues in Seerr.
Displays icons of available streaming services (from your default region) on Seerr Posters.

Requires TMDB API Key to be configured in Elsewhere Settings
Adds a Seerr tag to the External Links row on movie/show detail pages (the same row TMDB/IMDb icons appear in, and *arr links when enabled; it shows there regardless of whether *arr links are configured). If "Open results in More Info modal" above is enabled, clicking it opens that modal (status, downloads, and who requested it); otherwise it links straight to the item on Seerr.
Renders the Seerr detail-page link as the word "Seerr" instead of the icon. Independent of the *arr links "show as text" setting, so it applies even when *arr links are disabled.
Item Pages Discovery
Displays similar movies/shows from Seerr on item details pages. Limited to 20 items.
Displays recommended movies/shows from Seerr on item details pages. Limited to 20 items.
Adds a "Request More" button beside the Seasons section heading on Series detail pages when the show has unrequested seasons in Seerr. Lets users request additional seasons without going through the search bar.
Hide similar/recommended items that already exist in your Jellyfin library from the results.
If disabled, the items that are available link to the media item in the library.
When enabled, items marked as blocklisted in Seerr will not appear in similar/recommended suggestions.
"More" Discovery
When viewing a network page (e.g., Netflix, HBO), displays additional content from that network available in Seerr.
When viewing a genre page (e.g., Action, Comedy), displays additional content in that genre from Seerr.
When viewing a tag page (e.g., cooking, superhero), displays additional content with that keyword from Seerr.
When viewing an actor/person page, displays their filmography from Seerr including content not in your library.
When viewing a collection/BoxSet page, shows movies from the collection that are not yet in your library with request buttons.
