Embed Activity in Custom Tabs: check_circleCustom Tabs detected

Display the Activity page in a Custom Tabs tab instead of the sidebar link.

You need the Custom Tabs plugin.

  1. Install the Custom Tabs plugin and all its prerequisites.
  2. Navigate to Dashboard > Plugins > Custom Tabs and add a new tab.
  3. Add "Display Text" according to your preference (e.g., "Activity").
  4. Copy the code below and paste it into the 'HTML Content' field.
<div class="jellyfinenhanced activity"></div>
