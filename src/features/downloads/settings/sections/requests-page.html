Requests Page shows a Requests Button in sidebar with a dedicated view of active downloads from Sonarr/Radarr and requests from Seerr.
Requirements: Configure Sonarr and/or Radarr, plus Seerr, URLs and API keys.
Adds a "Requests" link to the navigation showing active downloads and requests.
Shows active downloads from Sonarr/Radarr on the Requests page. (Requires *arr links and API keys to be configured)
When enabled, non-admin users only see downloads for content they requested. When disabled, all authenticated users can see every item in the download queue, including content requested by other users.
Shows open/resolved Seerr issues beneath Requests.
Shows a bounded history of recently imported (or failed-to-import) Sonarr/Radarr downloads beneath Requests, so items that vanish from the active queue after finishing are still visible.
When enabled, only Jellyfin administrators see the Download History section. Regular users won't see it at all.
Adds Requests as its own tab on the Home page, no external plugin needed.
Recommended on Jellyfin 12's experimental layout (the default).
Replaces the default Requests page with a Plugin Pages implementation.

Display the Requests page in a Custom Tabs tab instead of the sidebar link.

You need the Custom Tabs plugin.

  1. Install the Custom Tabs plugin and all its prerequisites.
  2. Navigate to Dashboard > Plugins > Custom Tabs and add a new tab.
  3. Add "Display Text" according to your preference (e.g., "Requests")
  4. Copy the code below and paste it into the 'HTML Content' field.
<div class="jellyfinenhanced requests"></div>
