Each page can appear as a native Home tab (no other plugin needed, and the most reliable choice on Jellyfin 12's Modern Layout), as a sidebar link through Plugin Pages, or as a Home tab through Custom Tabs. On the Modern Layout, sidebar links (Plugin Pages included) show only on phones. Plugin Pages 3.0 or newer applies a change without a Jellyfin restart; older versions need one the first time.
